# OldNotebookTextures

[https://gamebanana.com/mods/743525](https://gamebanana.com/mods/743525)

Basically, this mod modifies the texture of the notebook to make it look more like it is in 'BBC'/'BBCR'.

There is a configuration option that allows you to choose the style to restore.

Due to the use of Unity's AssetBundles system to load assets, this mod supports modifying mod textures with texture pack mods.

## Requirement

[BeplnEx](https://github.com/BepInEx/BepInEx/releases)
